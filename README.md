# Todo Application

A full-stack Todo Application developed to help users manage their tasks efficiently.  
The application provides user authentication and allows users to create, view, update, and delete their tasks.

## Features

- User Registration and Login
- JWT-based Authentication
- Create Tasks
- View Tasks
- Update Tasks
- Delete Tasks
- Persistent data storage using MySQL
- RESTful API-based backend

## Tech Stack
